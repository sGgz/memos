# TC-FE-001 发布笔记外层背景框为直角

- 类型：发布验证 / 样式回归
- 覆盖范围：`Explore` 页面已发布笔记外层背景卡片；当前实现位于 `web/src/pages/Explore.tsx`
- 跳过条件：若本次改动直接修改了 `Explore` 页面笔记外层卡片结构、类名、样式规则或相关渲染逻辑，则本用例先跳过旧预期回归，待新需求验证完后更新本用例再补测

## 前置条件

- 已完成前端改动代码提交到工作区
- 已在 `web/` 运行 `pnpm lint`
- 若验证发布版：已按顺序执行 `pnpm release` -> 仓库根目录 `scripts/build.sh`
- 已启动发布版服务，例如：`build/memos.exe --addr 192.168.1.38 --port 12345 --data ..\\run`
- 准备浏览器手机视口 `390x844`
- 测试账号：`root / 123`

## 执行步骤

1. 访问 `http://192.168.1.38:12345`。
2. 若未登录，则使用 `root / 123` 登录。
3. 用 `curl http://192.168.1.38:12345` 检查首页 HTML，确认引用的是当前最新构建产物的 JS/CSS hash。
4. 在浏览器打开 `http://192.168.1.38:12345/explore`。
5. 定位任意一条已发布笔记的外层背景卡片（特征：包住头像和 `MemoView` 内容的带边框背景容器）。
6. 记录该元素实际类名。
7. 检查该元素计算样式，重点记录 `border-radius`。

## 预期结果

- 服务端返回的首页资源 hash 与当前构建产物一致。
- 浏览器实际加载的是最新 hash 对应的资源，而不是旧资源。
- 已发布笔记外层背景卡片不包含圆角类名；当前期望类名可为 `border border-border/50 bg-background/90 px-2.5 py-2`。
- 目标元素计算样式 `border-radius` 为 `0px`。
- 页面在手机视口下显示正常，没有因卡片变直角导致布局错乱。

## 维护说明

- 若后续允许其他直角实现方式（例如通过共享 class 或 CSS 变量实现），只要最终计算样式仍为直角，可更新“当前期望类名”描述，但必须保留“检查计算样式”的要求。
- 若资源 hash 与浏览器加载不一致，优先清理/重开浏览器上下文，不要直接判定代码未生效。
